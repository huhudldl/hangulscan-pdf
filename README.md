# 한글스캔 PDF

Adobe Acrobat Reader를 참고해 만든 macOS용 PDF 뷰어입니다.
핵심 기능은 **한국어 OCR**과 **스캔 자동 수평 보정**이며, 모든 처리는 Mac 안에서 이뤄집니다(인터넷 불필요, Apple Vision 사용).

## Windows 버전

Windows 버전 설계는 [docs/WINDOWS_PORT.md](docs/WINDOWS_PORT.md)에 정리되어 있습니다.

## 설치 / 실행

```bash
./build.sh
```

`build/한글스캔 PDF.app`이 만들어집니다. 응용 프로그램 폴더로 옮겨 쓰면 됩니다.
(Xcode 없이 Command Line Tools만으로 빌드됩니다. macOS 26 이상)

## 기능

| 구분 | 기능 |
|---|---|
| 뷰어 | 페이지 썸네일, 목차(책갈피), 확대/축소·폭 맞춤, 한 페이지/연속/두 페이지 보기, 페이지 회전, 형광펜, 인쇄, 끌어다 놓기로 열기 |
| 검색 | 문서 전체 검색, 결과 목록·하이라이트, ⌘G / ⇧⌘G로 다음·이전 |
| 한국어 OCR | 스캔 PDF에 보이지 않는 텍스트 층을 입혀 **검색·복사 가능한 PDF**로 변환. 한국어+영어(선택: 일본어, 한자) |
| 스캔 | iPhone 연속성 카메라/Mac 카메라, 평판·급지 스캐너, 문서 사진 가져오기 |
| 자동 보정 | 문서 영역 자르기(원근 보정) → 90°/180° 방향 감지 → **수평 보정(0.05° 단위)** → 선명화 |
| 책 모드 | 펼친 양쪽을 두 쪽으로 분리 → 쪽별 수평 → **휜 글줄 펴기** → 테두리·가운데 그림자 정리 (세로 쪽 모양 유지) |
| 페이지 편집 | 한 쪽 삭제(⇧⌘D, ⌘Z로 되돌리기), 다른 PDF 합치기(끝에 / 현재 쪽 뒤에), 회전 — 왼쪽 사이드바 아래 단추·우클릭 메뉴 |
| 메뉴 숨기기 | ⇧⌘F로 도구 막대·사이드바·도구 패널을 한 번에 숨기고 문서만 보기, esc 또는 오른쪽 위 '메뉴' 단추로 다시 보이기 |
| 페이지 정리 | 전체 쪽을 격자로 보며 끌어서 순서 바꾸기, 여러 쪽 선택해 삭제·회전·맨 앞/뒤로·따로 저장 (⌥⌘P) |
| 폴더 자동 OCR | 지정 폴더에 PDF·사진이 들어오면 자동 보정·OCR → 'OCR 완료' 폴더, 원본은 '처리한 원본' |
| 인식 결과 교정 | 애매한 줄(주황)·글자 표시, 다른 후보 눌러 바꾸기, 고치면 검색 글자층에 반영 (⌥⌘E) |
| 표·문단 내보내기 | 표 → 엑셀(CSV, 병합 칸 반영), 문단 단위 텍스트 (macOS 26 문서 구조 인식) |
| 암호 PDF | 암호 PDF 열기, 저장 시 암호 유지, 암호 설정·해제 |
| 용량 줄이기 | 보통·작게·아주 작게(흑백) — 검색 글자 유지, 저장 전 결과 용량 표시 |
| 주석 | 형광펜·밑줄·취소선·메모·글상자·펜·사각형·원·화살표·지우개·서명 (⇧⌘A), ⌘Z 되돌리기 |
| 도우미 | 한국어 읽어주기, 번역(macOS 내장), 요약·질문(Apple Intelligence, 근거 쪽 표시) |
| 탭·최근 문서 | 여러 PDF를 탭으로(⌘T), 시작 화면·파일 메뉴의 최근 문서, 탭 닫을 때 저장 확인 |
| 대용량 | 중간 결과를 디스크에 두어 1000쪽도 메모리 일정(실측 300쪽 0.9GB), Mac 메모리에 맞춰 동시 처리 쪽수 자동 결정 |
| 실시간 수평계 | 카메라 스캔 중 문서 테두리와 기울기를 실시간 표시, 수평이 맞고 흔들림이 없으면 자동 촬영 |

## 단축키

| 키 | 동작 |
|---|---|
| ⌘O | 열기 |
| ⌘S / ⇧⌘S | 저장 / 다른 이름으로 저장 |
| ⌘K | 카메라로 스캔 (스페이스 = 촬영) |
| ⇧⌘K | 스캐너로 스캔 |
| ⇧⌘O | 전체 문서 한국어 OCR |
| ⇧⌘D | 현재 페이지 삭제 |
| ⌥⌘M | 문서 합치기 |
| ⇧⌘F | 메뉴 모두 숨기기/보이기 (esc로도 복귀) |
| ⌥⌘O | 현재 페이지 OCR |
| ⌘+ / ⌘- / ⌘0 / ⌘9 | 확대 / 축소 / 실제 크기 / 폭 맞춤 |
| ⌘R / ⌘L | 페이지 오른쪽 / 왼쪽 회전 |

## 수평 보정 원리

1. **글줄 분석**: Vision OCR이 찾은 각 글줄의 기울기를 길이 가중 중앙값으로 계산
2. **투영 분석**: 글자 영역의 어두운 픽셀을 각도별로 가로 투영해 줄이 가장 선명해지는 각도를 0.05° 단위로 탐색
3. 두 값이 1° 이내로 일치하면 정밀값, 아니면 글줄 값을 사용 → 이미지 회전

## 앱 아이콘 바꾸기

`Resources` 폴더에 이미지(png/jpg/heic)를 넣고 `./build.sh`를 실행하면 그 이미지가 앱·PDF 문서 아이콘이 됩니다.
둥근 사각형 바깥의 흰 배경은 자동으로 투명하게 처리됩니다.

## 자동 시험

```bash
./scripts/regression.sh
```

테스트 이미지(`scripts/make_test_assets.swift`)를 만들어 OCR·수평 보정·표 인식·교정·용량 줄이기·쪽 크기·폴더 자동 OCR 등 17개 항목을 확인합니다.

## 터미널 테스트 모드

```bash
".build/release/HangulScan" --selftest 입력.png 결과.pdf
".build/release/HangulScan" --selftest 스캔.pdf 결과.pdf --force --dpi 600
".build/release/HangulScan" --selftest 책사진.jpg 결과.pdf --book
".build/release/HangulScan" --selftest 사진폴더/ 결과.pdf
```
